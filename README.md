El archivo code incluye todos los .py's empleados en la práctica de diffussion models.
Se trata de una práctica en la que usando diferentes métricas de diffussion models y algoritmos, como VP, VE... observamos cómo se generan los dígitos manuscritos
del dataset de MNIST. Se ven las diferencias entre procedimientos estocásticos y deterministas, y se evalúan entre ellas mediante la comparación de resultados.

Este trabajo se realizó de manera conjunta con Miguel Borregón
